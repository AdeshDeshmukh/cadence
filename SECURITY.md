## Reporting a Vulnerability

Cadence is built with privacy-first and on-device principles. If you discover a security vulnerability or potential privacy leak:

1. **Do not open a public issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the repository maintainers.
3. Provide descriptive steps to reproduce the issue along with environment details.

All valid security reports will receive acknowledgment and will be reviewed promptly.
